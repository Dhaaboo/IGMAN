IGMAN.Web — Actual Frontend Assets

Copy the contents of this folder into:
IGMAN.Web/wwwroot/assets/

Folders:
logo/         IGMAN logo, app icon, favicon
icons/        individual feature icons (SVG + PNG)
backgrounds/  futuristic UI wallpapers
avatar/       IGMAN profile/AI/3D avatar images
flag/         Somaliland flag SVG/PNG variants
voice/        UI interaction/state WAV sounds
ui/           status badges, Somali mode, waveform, theme CSS
misc/         brain/star utility graphics

Note:
The WAV files are UI interaction/state sounds, not spoken Somali TTS.
